# DagGer 使用说明

## 简介

DagGer 是一款用于对主域名进行信息收集的单兵工具，主要用于子域名扫描和目录扫描。

**作者**：CatFl0g

---

## 功能特性

- **备案查询**：通过第三方接口查询主域名备案信息
- **子域名扫描**：基于字典对主域名进行子域名爆破，检测存活子域名并提取网页标题
- **目录扫描**：对存活的子域名进行目录爆破，记录响应码
- **多线程加速**：子域名扫描使用 100 线程，目录扫描支持 10 个域名并发
- **随机 User-Agent**：内置多个 UA，每次请求随机选取，降低被识别风险
- **信号处理**：支持 Ctrl+C / SIGTERM 强制退出

---
